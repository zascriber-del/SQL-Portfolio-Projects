Welcome! This repo holds my SQL portfolio projects. I'm using it to build and show my data analysis skills as I move toward an analyst role. I'll keep adding new SQL projects here as I finish them.

## Projects

### COVID-19 Data Exploration
An exploratory analysis of global COVID-19 data (Jan 2020 – Apr 2021) using two datasets: **CovidDeaths** and **CovidVaccinations** (~85K rows each).

**Questions explored:**
- How likely was a person to die after contracting COVID in their country?
- What percentage of each country's population was infected?
- Which countries and continents had the highest death counts?
- How did vaccination rates grow over time relative to population?

**Skills used:** Joins, CTEs, temp tables, window functions, aggregate functions, data type conversions, and creating views for later visualization.

**Files:**
- `COVID_Portfolio_Project_SQL.sql`: the queries
- `CovidDeaths.xlsx` / `CovidVaccinations.xlsx`: source data
